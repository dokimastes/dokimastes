# Dokimastes

Dokimastes is an open-source framework for running agentic software delivery under enforced, evidence-producing gates.

It does not make you compliant, and it is not a "dark factory". It discharges named obligations with retained evidence when deployed as specified. Nothing more is claimed.

The invariant: **an agent that can edit the gate is not gated.** Enforcement lives in git and the operating system, never in the agent's harness.

- CLI: `dok`
- Consumer surface: `dok.yaml` and `.dok/`

Named after the δοκιμαστής, the public assayer of Nikophon's coinage law (Athens, 375/4 BC), who tested coin by statute and could not be a party to the transaction.

Status: pre-release, nothing is usable yet. Licence: Apache-2.0.
